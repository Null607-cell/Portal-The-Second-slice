# EXPERIENCE THE PORTAL 2 THAT NEVER WAS.



_"Imagine a alternative universe where Portal 2 had the same atmosphere and aesthetic
as the original Portal and where it still had that sense of creepiness and vibe it gave off."_


> **About the mod** <

Portal: The Second Slice is a free modification that attempts to continue the events of the
original Portal right after GLaDOS's destruction. Unlike Portal 2, this mod aims to retain the
original aesthetic and atmosphere that encapsulated the original Portal. This mod features
a fully custom storyline, that's inspired by a early rendition of Portal 2's storyline that was originally
planned but ultimately scrapped during development. This mod also has a original Soundtrack,
that is also heavily inspired by Portal 1's soundtrack, although using some of Portal 2's melodies.
We also use a Custom engine branch developed by ChicK The Crocodile, by the name
'Portal: Modding advanced' that brings along some features from Portal 2 into the original Portal.
Like Lasers, faith plates and light-bridges. This mod has no planned release date, as the scope is
extremely big and the team of this mod consists of very few people with a rudimentary understanding
on how the source engine works. A Demo is available of chapter one on ModDB, although its extremely outdated
and does not have the aforementioned engine branch and we longer use ModDB. And a lot of changes
has been made since the demo has been released and we do plan on releasing a new version pretty soon, so stay tuned!
